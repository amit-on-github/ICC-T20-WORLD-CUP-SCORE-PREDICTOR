# 🏏 ICC T20 World Cup Score Predictor

A Machine Learning-powered web app to predict the score in ICC T20 World Cup matches. This project uses historical cricket match data and statistical models to forecast the expected score based on match conditions.

![Banner](https://img.shields.io/badge/Python-ML-blue?style=for-the-badge) ![Status](https://img.shields.io/badge/Status-Completed-brightgreen?style=for-the-badge)

## 📌 Features

- Predict total score for T20 matches based on inputs like:
  - Batting team
  - Bowling team
  - Current score
  - Overs left
  - Wickets remaining
  - Run rate
- Simple and intuitive web interface using Streamlit
- Trained on real ICC T20 data
- Deployed locally and easy to run

## 🚀 Getting Started
[👉Predict Score](https://icc-t20-world-cup-score-predictor-ignitjznbmz6yyflsphnp2.streamlit.app/)

Follow these steps to run the project locally.

```bash

git clone https://github.com/amit-on-github/ICC-T20-WORLD-CUP-SCORE-PREDICTOR.git

# Navigate to the directory
cd ICC-T20-WORLD-CUP-SCORE-PREDICTOR

# Install dependencies
